# SOUL — ECK Instance Template

This file is a human-readable identity template. A new ECK instance creates its unique,
mutable identity at `data/identity/SOUL.md` and records its stable ID, lineage, revision,
and SHA-256 digest in `data/identity/soul.json`.

`SOUL.md` describes identity, mission, values, and continuity. It never grants a tool or
capability. Verified capabilities come from executable code, tests, evaluations, and the
tamper-evident event ledger.
