### Added

  and line-count ratchets on oversized files.

  proof before any real database upgrade.
- A unified `skill-lifecycle.v1` read model and centralized runtime-skill transition policy.
- Explicit experimental packages for P6 missions and P7 federation with backward-compatible
  import facades.
- Evidence-grounded current-information research with GDELT discovery, retained source
  provenance, claim-level support/contradiction links, and explicit uncertainty.
- In-memory raw response buffers, compressed 30-day cleaned-text retention, SHA-256/SimHash
  duplicate grouping, and permanent source metadata in SQLite.
- A rolling quality gate that marks research degraded when more than half of the latest ten
  completed runs are inconclusive.
- A read-only public research operation surface isolated from future state-changing browser
  workers, plus research run and quality APIs.
- P6 durable software missions with persistent dependency graphs, auditable ReAct summaries,
  restart recovery, deterministic website validation, Docker-tested Python projects, local
  previews, SHA-256 packages, quota isolation, and dedicated-account GitHub publication.
- P6 quality council with current-reference retrieval, six persisted architect microtasks,
  three mandatory independent review/improvement rounds, creator-feedback replay, approved-only
  pattern reuse, topic-plus-sequence repository names, and refresh-safe dashboard review drafts.
- P6 v3 non-degrading website delivery with verified design baselines, expanded visual/language/
  interaction contracts, deterministic broken-asset repair, and urgent-mission foreground
  scheduling without removing expert review rounds. Low-memory pressure now pauses model-heavy
  work without blocking deterministic packaging, publication, distillation, or submission.
  Dedicated-account GitHub updates now use an isolated `gh` credential helper instead of the
  workstation's active Git credential, and interrupted private-repository pushes recover safely.
- P7 ECK Federation foundation with privacy-scanned Evolution Skill Packs, SHA-256 inventories,
  local version-diff plans, quarantine, isolated receiver reproduction, two-node admission, and
  normal local Canary validation before activation.

  Cosign signing and trust-policy verification; candidate review, trust scoring, revocation, and a

  pack diversity and evaluation evidence exist.
- Provenance-aware open-source capability acquisition with pinned GitHub inspection, permissive
  license gating, strategy-versus-runtime classification, deterministic generated manifests,
  immutable operator acceptance examples, dependency/security preflight, Docker restoration,
  bounded repair, Canary activation, and honest failed-candidate history.
- Branded SVG web assets, responsive dashboard overflow hardening, a Windows desktop launcher,
  one-click source installer, and tag-driven GitHub Release packaging.
- One-click autonomous-learning pause and full-kernel shutdown controls, Ollama startup assurance,
  and workload-managed local model residency with on-demand Forge activation.
- Raw-prompt Forge fallback when image prompt planning is unavailable, while preserving honest
  runtime state and reproducible artifact checks.
- Verification-directed deliberation with at most five sequential software roles: architect,
  implementer, reviewer, tester, and integration optimizer; only structured summaries are retained.
- Portable SQLite vector retrieval using BGE-M3 embeddings and the exact
  `BAAI/bge-reranker-large` reranker, with twenty-candidate retrieval reduced to two grounded items.
- A persistent one-hundred-tool GitHub learning campaign that counts only permissively licensed

- A fail-closed GitHub CLI policy backed by Credential Manager, with account, credential, payment,

- ECK Workspace with an outcome-first dark shell, natural-language composer, durable project
  browser, refresh-safe drafts, artifact preview/download links, rebuildable Library projection,
  unified skill lifecycle view, view-aware polling, and non-blocking cached system summaries.

## [0.1.0] - 2026-08-02

### Added

- Persistent Digital Life lifecycle and clean/unclean recovery.
- Tamper-evident SQLite event chain and JSONL export.
- Versioned Success Contract and forbidden-condition model.
- Graded Policy Gate with human approval.
- External-evidence and reproduction verifier.
- Experience admission, evidence-grounded Knowledge records, deterministic
  Reflection records, and two-success Skill activation.
- Mock and Ollama brain adapters.
- Safe Python expression and GridWorld capabilities.
- CLI, REST API, OpenAPI, and local dashboard.
- Docker Desktop/WSL2 deployment hardening.
- Python test suite and experimental Rust integrity verifier.
- Thirteen-volume v0.1 specification.
- Local-first dialogue, bounded Crossref research, an idle supervisor, and a visible
  learning-status dashboard.
- Persistent missions, monthly challenges, evaluation records, and version-governance
  rules with human completion review.
- Docker-isolated generated skills with validation before hot activation.
- Local Stable Diffusion WebUI Forge integration with three verified SD1.5 checkpoints,
  ADetailer, ControlNet OpenPose, and rembg/BiRefNet background removal.
- A Windows-safe release verifier covering Ruff, strict MyPy, 88 tests, branch coverage,
  live Uvicorn acceptance, and Docker image construction.

### Explicitly not included

- Autonomous model-weight updates.
- Arbitrary host shell execution or untested generated-code activation.
- Unrestricted web access; research remains bounded to registered, allowlisted adapters.
- Desktop control or robotics.
- Claims of AGI, consciousness, or abstract generalization.

### Validation

- Release gate: passed on 2026-08-02.
- Test suite: 88 passed; branch coverage: 80%.
- Live acceptance: lifecycle persistence, event-chain integrity, safe expression, and
  measurable GridWorld experience reuse passed.
- Docker application and isolated skill-worker images built successfully.
- Rust check was skipped because Cargo was not installed; it remains an optional
  environment-specific verifier.
