# ECK

Experimental Cognitive Kernel

An experimental AGI framework focused on autonomous cognition, memory, reasoning, planning, and continuous self-improvement.
ECK (Experimental Cognitive Kernel) is an experimental AGI framework that explores how autonomous intelligent systems can integrate long-term memory, reasoning, planning, knowledge management, and tool usage into a unified architecture.

The project emphasizes system architecture rather than training new foundation models, aiming to build a scalable cognitive operating framework for future AGI research.
