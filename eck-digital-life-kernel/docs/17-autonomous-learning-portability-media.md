# 自主學習、可攜大腦與本機媒體能力

**狀態：** v0.2 Development  
**目前套件版本：** v0.1.0；本文件與實作不代表 v0.2.0 已發布

## 1. 持續學習的正確定義

ECK 應在醒著時持續尋找高資訊增益、可驗證且不重複的工作，但不應以 GPU 使用率、
事件數或文字產量當作學習成果。等待網站限流、模型冷卻、證據交叉檢查、排程空檔與
資源回收都是正常狀態。真正的進步必須表現在保留題、真實任務、重現率、成本或完成
時間上，而不是永遠讓硬體滿載。

目前的自主課程排程器以五分鐘為預設學習時槽，每日最多建立 144 個候選研究，依日期
輪替領域與研究角度。它不再要求監督者先進行昂貴推理才有工作，也不會因為監督者略過
重複題目而永久空轉。研究仍需通過來源、主張、反證與重現檢查才能成為正向經驗。

## 2. 快速且有根據的學習驗證

每次宣稱「變聰明」前，至少執行以下比較：

1. 固定版本的 20–50 個保留真實任務，事前凍結輸入、評分規則與時間／資源上限。
2. 比較基線、啟用記憶、啟用技能，以及記憶關閉與技能關閉的消融結果。
3. 量測正確率、合約通過率、可重現率、完成時間、GPU 時間、失敗類型與人工介入次數。
4. 使用程式驗證器、外部證據與真人抽查；模型不得單獨判定自己已進步。
5. 加入未看過的遷移題和回歸題，避免只記住原題或因新增技能破壞舊能力。
6. 保存資料集版本、執行環境、模型雜湊、來源與完整負面結果。

只有保留題改善、信賴區間合理、回歸未惡化且消融證明增益確實來自新記憶或技能時，
才把能力增強列為已驗證。單一成功案例與技能數增加都不足以證明一般能力提升。

## 3. 可攜數位大腦

`CognitiveBundleService` 會建立 `eck-cognitive-bundle.v1` ZIP 封裝，內容包含一致性的
SQLite 線上備份、設定、鎖定檔、模型目錄、已生成的熱技能原始碼，以及逐檔 SHA-256
清單。API 可建立、下載並驗證封裝：

```text
POST /v1/portability/bundles
GET  /v1/portability/bundles/{archive_name}
GET  /v1/portability/bundles/{archive_name}/verify
```

預設不封裝密鑰、Ollama 權重、Stable Diffusion 或影片模型，因為它們可能非常大且有各自
授權。移轉時必須另外安裝清單指定的相容基礎模型與依賴，驗證模型雜湊，啟動唯讀複本，
重播事件鏈，最後執行技能與保留題回歸。完成跨機還原演練前，只能宣稱「可匯出與驗證」，
不能宣稱已保證在任意系統完整復活。

## 4. 本機影片生成

`video.generate` 使用官方 FramePack 的本機推理程式。它先建立或接受第一幀，再由獨立
程序產生 MP4，保存輸入、模型、時間與 SHA-256 證據。3060 Laptop 6 GB VRAM 可啟動
官方低顯存路徑，但速度、系統記憶體與影片長度仍是實際限制；預設採短片、單工作、
無並行 Forge/Ollama 推理的策略。

本機 16 GB RAM 實機煙霧測試在載入 HunyuanVideo 第 2/4 分片時由程序退出，因此目前
狀態會如實顯示「模型已安裝、資源閘門未通過」，不會假報 READY。ECK 的參考操作閘門
暫設為總 RAM 至少 24 GB 且當下可用 RAM 至少 12 GB；這是依本機失敗結果設定的保守
下限，不是保證任意 24 GB 系統都能完成生成。建議升級到 32 GB RAM 後重新執行完整 MP4
驗證；在此之前，程式與模型可保留供未來硬體使用。

ECK 不提供「越獄」或停用所有保護的模式。設定可允許合法成人內容，但永久拒絕未成年、
非自願、性暴力、動物性內容與其他違法用途。這是能力邊界，不是外部付費 API 限制。

## 5. 端到端自主工作的現況

目前 ECK 能在已註冊能力內完成「規劃候選動作 → 執行 → 收集外部證據 → 驗證 →
沉澱經驗／技能」的有界工作，但還不是能處理任意數位任務的 AGI。要朝目標前進，
v0.2 仍需補齊：

- 分層目標／子任務規劃器與失敗後的修復迴圈；
- 唯讀研究 Worker 與會改變外部狀態 Worker 的物理隔離及政策閘門；
- 能力缺口偵測、技能合成、隔離測試、熱切換與全套回歸；
- 任務世界狀態、預算、期限、依賴與可恢復檢查點；
- 固定評測、遷移題、消融與跨版本能力曲線；
- 通過人工核准的 LoRA／偏好訓練候選流程，而非把 RAG 記憶誤稱為權重訓練；
- 跨機還原演練與模型／套件授權清單。

關鍵不是讓模型無限制行動，而是讓每次行動都可恢復、可驗證、可量化，並讓成功方法
能在新任務重用。這才是可長期累積且可複製的工程路徑。
