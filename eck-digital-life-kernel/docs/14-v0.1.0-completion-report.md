## Formal v0.1 acceptance

1. **Persistent life and recovery:** passed. Identity, boot count, lifecycle state,
   SQLite memory, and tamper-evident events survive process reconstruction.
2. **Safe expression:** passed. A fixed Success Contract, unit-test evidence, and formal
   checks admit only verified results.
3. **GridWorld learning:** passed. The first exploration takes 23 steps and verified
   route reuse takes 11 steps under a changed surface label. This demonstrates bounded
   experience reuse, not abstract general intelligence.
4. **Event integrity:** passed. The live event-chain verifier reports a valid chain.

## Completed extension scope

The current implementation exceeds the original v0.1 feature list in controlled areas:

- local Ollama dialogue with admitted-memory and active-skill grounding;
- bounded academic research through registered public metadata adapters;
- a rate-limited supervisor with duplicate-topic suppression;
- persistent editable missions, challenge contracts, and human completion review;
- a 90/10 autonomous-learning and challenge allocation policy with urgent overrides;
- Docker-isolated skill validation, dependency installation, and hot activation;
- foundation skills for public-web inspection, browser tasks, documents, artifacts,
  workspace files, Git operations, data analysis, task planning, and social policy gates;
- local Forge image generation using verified Realistic Vision, ChilloutMix, and
  CyberRealistic checkpoints, plus ADetailer and ControlNet OpenPose;
- local rembg/BiRefNet-General background removal; and
- a dashboard centered on dialogue, current autonomous activity, verified learning,
  missions, and runtime status.

On the final live snapshot, the running kernel reported boot count 33, a valid event
chain, 33 admitted experiences, 13 skills, Forge ready, and background removal ready.
These counts are operational telemetry and will continue changing after this report.

## Defects found and corrected during release audit

- The release verifier could hang while hashing the multi-gigabyte local model workspace;
  runtime workspaces are now excluded from the source-tree digest.
- Windows code-page decoding could crash Docker output capture; subprocess output is now
  decoded as UTF-8 with replacement.
- The live verifier previously spawned a launcher child that could retain the SQLite
  database; it now runs a real localhost Uvicorn server in a controlled thread and
  verifies clean shutdown.
- Test fixtures could write into production image catalog and rembg script paths; every
  test path is now isolated under its temporary workspace.
- An empty image prompt could be expanded into a quality suffix and reach the engine;
  empty descriptions are now rejected before prompt enhancement.
- The restored rembg worker was exercised against an actual generated 512×512 image and
  produced a verified transparent PNG locally.

## Current verified limits

- The `qwen3:4b` model weights have not been trained by ECK. Growth currently occurs in
  persistent memory, verified procedures, skill activation, scheduling, and tooling.
- Research quality is bounded by accessible source metadata and verifier rules. A
  deterministic grounded fallback may succeed when model synthesis fails; that is not
  evidence that the base model improved.
- No official social-platform adapter or authenticated account automation has been
  verified. ECK must not claim that it posted, messaged, or received engagement without
  externally reviewable evidence.
- Structural self-modification and model-weight promotion still require complete tests
  and human approval. Arbitrary host shell access remains unavailable.
- ECK v0.1.0 is not verified as AGI, conscious, autonomous beyond its registered
  capabilities, or superior to human knowledge.

## Version decision

The original v0.1 acceptance contract is satisfied and the added features remain inside
registered, testable boundaries. v0.1.0 can therefore be closed and published. v0.2.0
may begin as a separately specified capability-growth release without rewriting this
historical acceptance record.
