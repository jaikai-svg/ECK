# Changelog

All notable changes are documented here.

## [0.1.0] - 2026-08-02

### Added

- Persistent Digital Life lifecycle and clean/unclean recovery.
- Tamper-evident SQLite event chain and JSONL export.
- Versioned Success Contract and forbidden-condition model.
- Graded Policy Gate with human approval.
- External-evidence and reproduction verifier.
- Experience admission, evidence-grounded Knowledge records, deterministic
  Reflection records, and two-success Skill activation.
- Mock and Ollama brain adapters.
- Safe Python expression and GridWorld capabilities.
- CLI, REST API, OpenAPI, and local dashboard.
- Docker Desktop/WSL2 deployment hardening.
- Python test suite and experimental Rust integrity verifier.
- Thirteen-volume v0.1 specification.
- Local-first dialogue, bounded Crossref research, an idle supervisor, and a visible
  learning-status dashboard.
- Persistent missions, monthly challenges, evaluation records, and version-governance
  rules with human completion review.
- Docker-isolated generated skills with validation before hot activation.
- Local Stable Diffusion WebUI Forge integration with three verified SD1.5 checkpoints,
  ADetailer, ControlNet OpenPose, and rembg/BiRefNet background removal.
- A Windows-safe release verifier covering Ruff, strict MyPy, 88 tests, branch coverage,
  live Uvicorn acceptance, and Docker image construction.

### Explicitly not included

- Autonomous model-weight updates.
- Arbitrary host shell execution or untested generated-code activation.
- Unrestricted web access; research remains bounded to registered, allowlisted adapters.
- Desktop control or robotics.
- Claims of AGI, consciousness, or abstract generalization.

### Validation

- Release gate: passed on 2026-08-02.
- Test suite: 88 passed; branch coverage: 80%.
- Live acceptance: lifecycle persistence, event-chain integrity, safe expression, and
  measurable GridWorld experience reuse passed.
- Docker application and isolated skill-worker images built successfully.
- Rust check was skipped because Cargo was not installed; it remains an optional
  environment-specific verifier.
