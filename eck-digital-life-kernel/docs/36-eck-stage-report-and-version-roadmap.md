# ECK 現階段報告與版本路線

更新日期：2026-08-27

## 結論

ECK 目前是「可長期運行、可稽核、能執行工具與持久化任務、能在隔離環境產生技能與核心候選」的本機認知執行系統。它已超出最初 v0.1.0 的功能範圍，但執行套件版本仍維持 v0.1.0；工程階段編號不等於正式版本，也不構成 AGI 證明。

目前沒有證據證明 ECK 已是 AGI、世界前 1% 軟體工程師、能無限制自主改善，或已訓練 Qwen 基礎模型權重。已驗證的是周邊認知架構、記憶、技能、任務、成果、評估及受治理的候選修改流程。

## 現在仍缺少的關鍵證據

1. 長時間真實任務成功率是否持續提高，而非只增加事件或記憶數量。
2. 不同時間、不同隱藏測試與人工盲評下的非退化能力增長。
3. 高品質程式模型在 RTX 3060 上的穩定吞吐與大型專案修復能力。
4. 自動建立獨立評估器時不洩漏答案、不迎合候選程式的機制。
5. Linux、Docker 與 CLI 啟動方式的外部 watchdog、藍綠切換及災難回復。
6. 基礎模型 Adapter、蒸餾或權重更新對能力的可重現增益。

## 正式版本路線

### v0.1.x：可靠自治核心

- 完成 P8 自治演化導引器、真實失敗聚合、評估包綁定與操作介面。
- 補齊跨平台 watchdog、任務陰影重播與長時間 soak test。
- 維持 REST API、SQLite 舊資料及技能格式完全向後相容。

### v0.2.0：證據原生自治軟體工程師

- 以真實 issue、隱藏測試、效能門檻及人工驗收衡量程式能力。
- 建立獨立 evaluator sandbox，避免修改者同時控制答案與評分。
- 強化專案檢索、架構理解、微任務規劃、除錯及非退化重構。
- 只有所有 v0.2.0 release gates 通過才變更正式套件版本。

### v0.3.0：可攜與聯邦認知成長

- CognitiveBundle v3 安全匯入、差異預覽、選擇性合併及隱私清洗。
- Evolution Pack 公共 Registry、Cosign 身分驗證、多節點重現與 Trust Engine。
- NAS 分層儲存、硬體路由及跨設備能力重測。

### v0.4.0：受治理模型學習

- 相容基礎模型的 LoRA／PEFT 候選實驗室。
- Teacher–Student 蒸餾資料、污染檢查、固定與隱藏評估。
- Adapter 只能在量化增益且無安全或能力回歸時進入 Canary。

### v0.5.0：多節點數位生命執行層

- 跨平台 Worker、節點協調、藍綠核心、資源排程與故障轉移。
- 每個節點保有獨立 SOUL、私人記憶、主人設定與成長血統。

### v1.0.0：外部驗收的通用自治系統

v1.0.0 只能由跨領域真實任務、長時間可靠性、隱藏評估、外部專家審查、安全治理及可重現能力提升共同支持。版本名稱不得自動宣稱 AGI；AGI 或超人能力必須由外部證據判定。

## 版本治理

- 沿用既定規則：完成當月課題且有實質更新時才切換大版本；每增加 100 個已驗證技能才切換小版本。
- 版本切換仍需符合 release gates，不能只因日期、事件數、運行時間或模型自我宣稱而更新。
- P6、P7 與新研究模組在介面穩定與客觀驗收前保留 Experimental 標記。
