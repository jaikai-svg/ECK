# Changelog

All notable changes are documented here.

## [0.1.0] - 2026-07-29

### Added

- Persistent Digital Life lifecycle and clean/unclean recovery.
- Tamper-evident SQLite event chain and JSONL export.
- Versioned Success Contract and forbidden-condition model.
- Graded Policy Gate with human approval.
- External-evidence and reproduction verifier.
- Experience admission, evidence-grounded Knowledge records, deterministic
  Reflection records, and two-success Skill activation.
- Mock and Ollama brain adapters.
- Safe Python expression and GridWorld capabilities.
- CLI, REST API, OpenAPI, and local dashboard.
- Docker Desktop/WSL2 deployment hardening.
- Python test suite and experimental Rust integrity verifier.
- Thirteen-volume v0.1 specification.

### Explicitly not included

- Autonomous model-weight updates.
- Arbitrary shell or generated-code execution.
- Internet research capability.
- Desktop control or robotics.
- Claims of AGI, consciousness, or abstract generalization.
