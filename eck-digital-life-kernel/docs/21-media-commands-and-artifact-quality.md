# Media Commands & Artifact Quality

狀態：**Implemented / Experimental**

## 指令格式

- `/image <描述>`：本機圖片生成。
- `/image nsfw 9:16 <合法成年內容描述>`：決定性成年媒體提示，不經通用 LLM 改寫。
- `/video 16:9 5s <描述>`：指定比例與秒數的本機影片生成。
- `/video nsfw 9:16 5s <合法成年內容描述>`：決定性成年影片提示。
- 支援比例：`1:1`、`9:16`、`16:9`、`2:3`、`3:2`；圖片另支援安全範圍內的 `寬x高`。

## 需求保真

- 提示規劃器若回傳系統指令、遺漏裸體、全身、國籍或脫衣動作等必要條件，結果視為規劃失敗。
- 合法成年內容直接使用決定性提示編譯器，避免通用文字模型自行加上衣物或改寫主題。
- 全身構圖會加入頭到腳、腳部可見、遠景及不可裁切約束；前端依實際圖片尺寸顯示，不再強制方形。
- 東亞人物預設使用 ChilloutMix；明確指定的模型名稱仍具有最高優先權。

## 影片驗證

- MP4 使用 H.264 相容封裝並嘗試加入 fast-start metadata，前端同時提供播放器與直接下載。
- CogVideoX 輸出新增邊緣能量與時間變化檢查；近乎純色、模糊崩壞或沒有動態的結果不得標記成功。
- 驗證器同時核對時長、寬度、高度、檔案存在與 SHA-256。
- 目前仍未部署視覺語言語意裁判，因此「人物與動作完全符合描述」仍屬下一階段能力，不得僅由檔案存在推定。
