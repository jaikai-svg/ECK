# ECK 導向社群技術學習

**狀態：** v0.2 Development  
**目前套件版本：** v0.1.0；本功能不代表 v0.2.0 已發布

## 1. 目標

自主課程預設以 70% 學習時槽研究與 ECK 自身能力直接相關的主題，30% 保留給經濟、
管理、科學與社會等一般領域，避免只會改進代理架構卻失去廣度。ECK 技術主題包含：

- Agent Skills、MCP、工具介面與能力隔離；
- 分層規劃、耐久執行、檢查點、失敗修復與回滾；
- RAG、長期記憶、資料來源、上下文工程與提示注入防護；
- 工作流自動化、多代理協作、瀏覽器代理與可觀測性；
- 本機模型量化、GPU 排程、評測、合成資料與驗證器；
- 自動技能合成、隔離測試、回歸與自我修改安全。

## 2. 可信來源目錄

`config/community-sources.json` 只收錄官方規格或專案維護者來源。目前包含 Agent Skills、
MCP、LangGraph、OpenHands、MiniMax Skills、AutoGen 與 OpenAI Agents SDK。目錄記錄擁有者、
來源 URL、信任層、授權及採用模式；`GET /v1/learning/community-sources` 可檢查現行清單。

來源被列入目錄不代表程式碼可直接執行，也不代表所有子目錄共用相同授權。`research-only`
只允許研究；`pattern-candidate` 允許 ECK 重新實作為自身架構的候選模式。

## 3. 技能採用閘門

社群技術進入正式技能前必須依序通過：

1. 確認官方擁有者、固定來源、授權與版本；
2. 將網頁、README、issue 與程式碼視為不可信資料，不執行內嵌指令；
3. 找出 ECK 的真實能力缺口與可量測成功合約；
4. 重新實作最小 ECK 原生候選，不直接複製不明技能；
5. 在無密鑰、無主機檔案寫入、預設無網路的 Docker Worker 測試；
6. 執行安全掃描、舊技能回歸、保留題與負面測試；
7. 保存來源 commit、授權、測試、雜湊與失敗結果；
8. 通過後才熱啟用，結構性核心修改仍需人工核准。

學到一篇文章不是技能；只有跨新任務重用後仍能提高成功率、降低成本或減少人工介入，
才算能力增強。

## 4. 影片模型調查

截至 2026-08-08，ByteDance 官方 Seedance 2.0 頁面只提供模型介紹與產品能力，沒有提供
可下載權重。MiniMax 官方公開的影片工具是平台 API／MCP；MiniMax-M3 是大型語言模型，
不是可在 RTX 3060 上執行的開源影片模型。因此不能把兩者冒充為免費本機後端。

目前最接近本機條件的官方開放候選是 Apache-2.0 的 `zai-org/CogVideoX-2b`：模型約
13.8 GB，官方資料列出 Diffusers 最低約 5 GB VRAM，但必須使用 sequential CPU offload、
VAE slicing/tiling，速度會顯著下降。16 GB 系統 RAM 是否足夠仍必須以本機煙霧測試判定，
不能只根據 VRAM 表格宣稱順跑。未通過 MP4 實測前不會取代 FramePack 或顯示 READY。
