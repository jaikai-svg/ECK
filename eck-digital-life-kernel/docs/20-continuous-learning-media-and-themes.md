# Continuous Learning, Media Prompts & Themes

狀態：**Implemented / Experimental**

本文件記錄 ECK v0.1.0 在持續學習、主題式課程、媒體生成與監控介面的目前邊界。介面必須區分已驗證能力、實驗能力與未完成能力，不得把願景寫成既成事實。

## 持續學習

- `supervisor_max_reviews_per_day=0` 與 `autonomous_curriculum_max_runs_per_day=0` 表示不設每日次數上限。
- 自主課程依排程持續建立可驗證研究任務；監督者只負責品質檢查、反重複與提出改善，不代表整個學習核心。
- 無每日上限不等於無限制並行。單工作互斥、間隔、VRAM 釋放、證據驗證與失敗退避仍需保留，以避免 GPU 過熱、重複研究及低品質經驗污染。
- 只有通過成功契約、外部證據及驗證器的結果，才能進入正向經驗與技能記憶。

## 主題式自主課程

- 使用者可新增、暫停、恢復或刪除持久化學習主題。
- 課程預設保留 70% 給 ECK 自我改進核心，30% 給主題與一般知識探索。
- 每個主題會展開基礎機制、資料分析、經濟制度、社會倫理、地緣風險、工具工作流、反例限制及最新證據等研究視角。
- 主題與其後續驗證經驗會寫入可攜資料庫及匯出清單，方便移轉到另一台裝置。

## 圖片生成

- 對話路由會辨識「生成一位成年女性」等省略「圖片」字樣、但具有明確視覺主體的請求。
- 本機設定允許合法成年裸體與成人情色圖片；提示規劃器拒答時，能力層使用決定性英文提示備援，不會把模型拒答誤判成能力不存在。
- 未成年、非自願、性暴力、獸交及違法內容維持永久拒絕。

## 影片生成

- 中文自然語言先轉為保留人物、動作、場景、鏡位與時間動態的英文 CogVideoX 提示。
- 未要求空拍、城市或天際線時，這些元素會加入負面提示，降低不相關場景。
- 每次請求預設使用不同 seed；目前預設長度為 5 秒，CogVideoX 在本機設定上限為 6 秒。
- 已驗證項目是本機模型載入、MP4 產物、時長、雜湊與證據鏈。5 秒品質及語意符合度尚未完成硬體煙霧驗證。
- 後續應加入本機視覺語言模型裁判，比較原始需求、抽樣影格與動作描述；在此之前不得把「檔案可播放」等同「內容符合提示」。

## 課題介面

- 首頁每五秒更新監控資料。
- 前一次資料更新尚未完成時，不會再啟動重疊請求，避免慢速本機 API 形成輪詢風暴。
- 使用者展開進行中課題並編輯時，前端不得替換該清單 DOM，避免表單折疊或輸入遺失。
- 保存、提交、取消或手動關閉編輯後，才恢復完整即時重繪。
